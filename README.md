# Sindicato — Sesión 1

Plataforma de estudio para curso del sindicato. Sesión 1: Características de la educación, DHI, NEM, Fines y Criterios (LGE).

## Stack
- Next.js 14 (App Router)
- Tailwind CSS
- Framer Motion

## Correr localmente
```bash
npm install
npm run dev
```
Abre http://localhost:3000

## Contenido (Sesión 1)
- 3 mazos de flashcards (anclas + casos LITERALES del LGE)
- 3 exámenes tipo USICAMM con justificación

## Deploy en Vercel
1. Push a GitHub
2. Importar repo en vercel.com
3. Auto-deploy en cada push a main
